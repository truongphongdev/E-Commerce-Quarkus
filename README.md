# 🛒 E-commerce API - Quarkus Project

## 📝 Lưu ý cho cộng tác viên

- Dự án sử dụng **Lombok**, vui lòng cài đặt plugin tương ứng trên IDE để tránh báo lỗi cú pháp.
- Mọi thay đổi về cấu trúc Database nên được cập nhật thông qua việc sửa đổi các class trong package `entity`.

Dự án cung cấp hệ thống API cho nền tảng thương mại điện tử, được xây dựng trên nền tảng **Quarkus (Java 25)** với hiệu năng cao và khả năng khởi động siêu nhanh.

---

## 🚀 Công nghệ sử dụng

- **Java 25** (LTS)
- **Quarkus 3.35.2**
- **Hibernate ORM with Panache** (Active Record Pattern)
- **MySQL Database**
- **RESTEasy Reactive** (Jakarta REST)
- **Lombok & Hibernate Validator**

---

## 🛠 Yêu cầu hệ thống

Trước khi bắt đầu, hãy đảm bảo máy bạn đã cài đặt:

1.  **JDK 25**.
2.  **MySQL Server** (đang chạy).
3.  **IDE:** VS Code (cài thêm extension _Lombok_ và _Extension Pack for Java_) hoặc IntelliJ IDEA.
